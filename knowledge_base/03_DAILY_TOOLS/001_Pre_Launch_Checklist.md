# Pre-Launch Checklist (Universal)

## 🎯 Khi nào dùng tool này?

Trước khi go-live BẤT KỲ hoạt động nào public với cộng đồng:
- Bài đăng Fanpage/Website
- Event/UGC contest
- Tournament
- Campaign cross-channel
- Livestream/video lớn

## ⚡ Cách dùng nhanh

1. Chạy 7 nhóm check dưới đây theo thứ tự
2. Mỗi item: ✅ Pass / ❌ Fail / ⚠️ Cần verify
3. **Bất kỳ ❌ nào = không go-live**, fix trước
4. **3+ ⚠️ = escalate Lead** trước khi quyết định
5. Save kết quả check vào folder dự án + ngày go-live

---

## 📋 7 nhóm check

### 1️⃣ DATA (NĐ13)

```
[ ] Hoạt động có thu thập dữ liệu user không?
    → KHÔNG → skip section này
    → CÓ → tiếp tục

[ ] Loại data thu thuộc nhóm nào?
    □ Chỉ IGN/rank/Discord → Google Form OK
    □ Có SĐT/email/họ tên → BẮT BUỘC Promotion Tool
    □ Có CCCD/ảnh giấy tờ → ❌ KHÔNG ĐƯỢC LÀM (Red Line GSX-OP-007)

[ ] Form có consent checkbox bắt buộc không?
[ ] Form có nêu rõ purpose không?
[ ] Form có nêu rõ retention timeline không?
[ ] Có kênh cho user xem/sửa/xóa data của họ không?

→ Reference: GSX-OP-001, GSX-TOOL-003
```

### 2️⃣ CONTENT (Moderation)

```
[ ] Đã chạy Game Studio X Scanner trên TẤT CẢ creative chưa?
[ ] Bài có ảnh không?
    → Có → chạy Checklist 7 bước hình ảnh (GSX-TOOL-005)

[ ] ❌ RED LINE: Có bản đồ trong ảnh không?
    → Có bản đồ → DỪNG NGAY, không đăng (GSX-CASE-002)

[ ] Có chửi tục / viết tắt cách quãng không?
[ ] Có nội dung chính trị/tôn giáo/dân tộc nhạy cảm không?
[ ] Tone phù hợp với nền tảng đăng chưa?
    □ Website/Fanpage → Formal
    □ Group/Discord → Casual OK

[ ] Có từ ngữ tuyệt đối ("nhất", "duy nhất", "tốt nhất", "số một", "best", "top", "#1")?
    → KHÔNG → OK
    → CÓ → check tiếp:
        [ ] Đây có phải nội dung thương mại không? (banner/promo/landing/sponsored)
        [ ] Nếu CÓ thương mại: có tài liệu hợp pháp chứng minh không?
        [ ] Đã trình Brand Manager phụ trách sản phẩm duyệt chưa?
        [ ] Ấn phẩm có ghi rõ tên + số + thời gian tài liệu?
        → Bất kỳ NO nào: CHẶN, sửa trước go-live (GSX-OP-013)

→ Reference: GSX-OP-002, GSX-OP-013, GSX-TOOL-005
```

### 3️⃣ IP RIGHTS

```
[ ] Music dùng có license rõ ràng?
    □ Royalty-free (Epidemic Sound, Artlist, AudioJungle...)
    □ Tự sản xuất có hồ sơ
    □ Library có hợp đồng với VNG
    → ❌ KHÔNG dùng nhạc thị trường/cover/soundtrack game khác

[ ] Hình KOL/talent trong content còn trong hạn hợp đồng?
[ ] Logo VNGGames/sản phẩm có email approval Brand Manager?
[ ] Logo bên thứ 3 có file gốc + email cho phép?
[ ] Watermark bên thứ 3 đã xoá hoặc credit đúng?

→ Reference: GSX-OP-008
```

### 4️⃣ APPROVAL CHAIN

```
[ ] Bài lớn (banner main, video chính, announce sản phẩm) có 2nd-eye review?
[ ] Có email approval của Lead/Manager (theo cấp độ)?
[ ] Bài có Brand Manager involvement (logo, key visual) có email approval?
[ ] Nếu là tournament/giải đấu: có approval theo tier (xem GSX-TOOL-004)?

→ Reference: tất cả Operating Rules
```

### 5️⃣ DISCLAIMER & CREDITS

```
[ ] Nếu là UGC contest: có disclaimer ở caption chính + visual?
[ ] Nếu là giải đấu: có disclaimer 4 ý cốt lõi?
[ ] Credit đối tác/KOL/sponsor đầy đủ?
[ ] Hashtag chính thức của campaign đã có?

→ Reference: GSX-OP-007, GSX-OP-009, GSX-TOOL-007
```

### 6️⃣ POST-LAUNCH PLAN

```
[ ] Ai trực moderation 24h đầu?
[ ] Plan response khi có comment tiêu cực/vi phạm?
[ ] Có monitoring tool/spot-check mỗi 4-6h?
[ ] Backup plan nếu phát sinh sự cố (template incident report sẵn sàng)?

→ Reference: GSX-OP-006, GSX-OP-010, GSX-TOOL-008
```

### 7️⃣ DOCUMENTATION

```
[ ] Brief/plan đã save Drive nội bộ?
[ ] Source file thiết kế (PSD/AI) đã backup?
[ ] Contract/MOU với đối tác (nếu có) đã lưu?
[ ] Approval chain (email/screenshot) đã archive?
[ ] Compliance check kết quả đã save?

→ Reference: GSX-OP-011
```

## ⚠️ Lưu ý quan trọng

- **Không skip section vì "đã làm tương tự trước"**: rule có thể đã update
- **Khi 1 nhóm có ❌**: dừng toàn bộ, không partial-launch
- **Khi không chắc về section nào**: hỏi đúng owner theo `00_INDEX_VERSION/OWNERSHIP_MAP.md`
- **Sau go-live**: save checklist này có dấu ✅ vào folder dự án để audit

## 🚨 Red Lines tóm tắt (memorize)

Bất kỳ items dưới đây xuất hiện = **STOP NOW**:
- ❌ Bản đồ trong ảnh (GSX-CASE-002)
- ❌ Form thu CCCD/giấy tờ định danh (GSX-CASE-001)
- ❌ Nhạc bản quyền không phép
- ❌ Logo VNGGames/sản phẩm chưa có email Brand Manager
- ❌ UGC yêu cầu upload giấy tờ
- ❌ Giải đấu có sponsor nhóm cấm (cá độ, casino, crypto, rượu bia, thuốc lá, game khác)
- ❌ Từ ngữ tuyệt đối ("nhất", "duy nhất", "tốt nhất", "best", "top", "#1") không có chứng minh (HL 05/07/2026)
