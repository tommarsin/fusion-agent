# 03 - Daily Tools

## Mục đích folder

Các công cụ CTV / team Community dùng **hàng ngày**: checklist, decision tree, script library, template form, reference card.

**Đặc điểm**:
- Phải mở được nhanh, tra được nhanh
- Không viết dài dòng lý thuyết
- Mỗi tool có 1 mục đích cụ thể, không multi-purpose

Template chuẩn: `99_TEMPLATES/TEMPLATE_Daily_Tool.md`

---

## 4 loại tool

### A. Checklist (đếm step)
File `001_Pre_Launch_Checklist.md` - universal checklist trước khi go-live bất kỳ hoạt động nào
File `002_UGC_Event_Compliance_Checklist.md` - cho UGC contest
File `003_Form_Compliance_Checklist.md` - cho Google Form / Promotion Tool
File `004_Tournament_Compliance_Checklist.md` - 33 mục check cho giải đấu

### B. Decision Tree (nhánh quyết định)
File `006_Escalation_Decision_Tree.md` - khi gặp sự cố thì đi đâu

### C. Script Library (câu trả lời mẫu)
File `007_Scripts_Library.md` - phản hồi user/KOL/báo chí

### D. Template Form (mẫu cần fill)
File `008_Incident_Report_Template.md`
File `009_Consent_Checkbox_Templates.md`
File `010_NDA_Request_Template.md`

### E. Reference Card (1-pager tra cứu)
File `005_Content_Scanner_Guide.md` - hướng dẫn dùng Game Studio X Scanner tool
File `011_Quick_Reference_1pager.md` - cheatsheet treo bàn
File `012_Interactive_Playbook.html` - playbook tương tác (mở rộng từ playbook hiện có)

## Khi nào update folder này?

- Tần suất cao nhất so với Layer 1-2
- Khi có rule mới (Layer 2) → tạo tool tương ứng
- Khi team feedback tool không tiện dùng → revise
- Khi có case mới (Layer 4) → update checklist
